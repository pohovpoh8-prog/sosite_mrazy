# Сайт Дмитрия + Supabase

Сайт теперь подготовлен для настоящей общей базы комментариев через Supabase.

## 1. Создайте проект Supabase

Откройте официальный Supabase и создайте новый проект.

В Dashboard найдите **Connect** или **Settings → API Keys** и получите:
- Project URL;
- Publishable key.

Для браузерного приложения используется именно publishable key. `service_role` key в сайт помещать нельзя.

## 2. Создайте таблицу

Откройте **SQL Editor** в Supabase и выполните весь файл:

`supabase.sql`

Он создаст таблицу `comments`, включит RLS и разрешит:
- всем посетителям читать комментарии;
- всем посетителям добавлять комментарии.

Удаление через публичный сайт специально не разрешено.

## 3. Укажите данные проекта

Откройте:

`config.js`

и замените:

```js
window.SUPABASE_CONFIG = {
  url: "https://ВАШ-ПРОЕКТ.supabase.co",
  publishableKey: "ВАШ-PUBLISHABLE-KEY"
};
```

на данные своего проекта.

## 4. Запустите сайт

Можно открыть `index.html` локально или загрузить папку на хостинг.

После подключения комментарий, оставленный одним посетителем, будет сохраняться в PostgreSQL и отображаться другим посетителям.

## Безопасность

В проекте включён Row Level Security (RLS). Публичный браузер получает только необходимые права SELECT/INSERT.

Не публикуйте `service_role` key в `config.js`, HTML, GitHub или другом клиентском коде.

Для публичного сайта рекомендуется следующим этапом добавить антиспам/капчу и, если нужно, авторизацию администратора для удаления комментариев.
